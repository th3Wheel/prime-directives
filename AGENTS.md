# Agent instructions

Project rules for this repo live in `.prime-directives/local/`. Read every file there before you change anything. Start with `agent-pr-flow.md`: how an agent branch becomes a PR, and the commit-message sections the AI reviewer needs.

This file only points there, so the rules exist in one place. When Prime Directives are deployed here, the deploy tool moves this file into `.prime-directives/local/` and renders a generated `AGENTS.md` that points to the same folder.
