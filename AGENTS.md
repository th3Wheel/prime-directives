# Project agent rules

The project rules for this repo are the files in `.prime-directives/local/`. Read every file there before you change anything. Start with `agent-pr-flow.md`: how an agent branch becomes a PR, and the commit-message sections the AI reviewer needs.

This file is only a pointer, so the rules exist in one place. It is a hand-written file: the deploy tool keeps it by moving it into `.prime-directives/local/` when it renders the generated root `AGENTS.md`.
